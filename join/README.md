## 常见问题

**Q：申请后多久会收到回复？**
A：秘书处将在 3 个工作日内与您联系。

**Q：成员资格有效期多长？**
A：成员资格按年度计算，每年更新。

**Q：学术机构和高校可以申请吗？**
A：可以，欢迎科研机构和高等院校申请普通成员或白银成员。

**Q：已经是成员，可以升级级别吗？**
A：可以，请联系秘书处说明升级需求。
